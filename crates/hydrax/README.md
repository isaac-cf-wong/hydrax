# hydrax

Core-collapse supernova gravitational-wave simulation tools.

`hydrax` is the safe public API of the
[Hydrax](https://github.com/isaac-cf-wong/hydrax) workspace. It re-exports the
`hydrax-core`, `hydrax-wave`, and `hydrax-io` layers as one stable surface.

See the [repository README](https://github.com/isaac-cf-wong/hydrax) for usage
and the project roadmap.

# hydrax-core

Units, symmetric tensors, numerical conventions, and error types shared by the
[Hydrax](https://github.com/isaac-cf-wong/hydrax) crates.

This crate is an implementation detail of the `hydrax` public API. Depend on
[`hydrax`](https://crates.io/crates/hydrax) instead unless you need the
primitives directly.

# hydrax-wave

Quadrupole sources, observer-dependent polarizations, spectra, and
radiated-energy diagnostics for
[Hydrax](https://github.com/isaac-cf-wong/hydrax).

This crate is an implementation detail of the `hydrax` public API. Depend on
[`hydrax`](https://crates.io/crates/hydrax) instead unless you need the
waveform layer directly.

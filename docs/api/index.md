# API

The initial public API represents prescribed source quadrupoles, observer
geometry, and time-domain gravitational-wave polarizations:

- `SymmetricTensor3`
- `QuadrupoleSeries`
- `Observer`
- `FiniteDifference`
- `Waveform`
- `Window`
- `WaveformSpectrum`
- `ComplexAmplitude`
- `waveform_from_quadrupole`
- `sinusoidal_quadrupole`
- `ThirdDerivativeStencil`
- `EnergyDiagnostics`
- `radiated_energy`

Units, run configuration, and provenance surround that core:

- `GRAVITATIONAL_CONSTANT_M3_KG_S2`, `SPEED_OF_LIGHT_M_S`,
  `SOLAR_MASS_PARAMETER_M3_S2`, `SOLAR_MASS_KG`, `PARSEC_M`, `KILOPARSEC_M`
- `parsecs_to_m`, `kiloparsecs_to_m`, and their inverses
- `mass_to_geometrized_m`, `time_to_geometrized_m`, `energy_to_geometrized_m`,
  `density_to_geometrized_per_m2`, `pressure_to_geometrized_per_m2`,
  `speed_to_geometrized`, `power_to_geometrized`, and their inverses
- `read_configuration`, `ConfigurationError`
- `RunRecord`, `OutputRecord`, `write_provenance`
- `WaveformError`

Public Rust API documentation will be generated by `cargo doc` and published
to docs.rs when the crate is released.
